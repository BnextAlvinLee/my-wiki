# my-wiki

這是一個以 Laravel 為核心建立的個人 Wiki 專案，目標是提供簡單、可維護，且方便在本機與伺服器部署的知識整理環境。

## 專案規格

- **Laravel**：作為主要的應用程式框架，負責路由、MVC 架構、資料處理與整體開發流程。
- **PHP**：專案主要使用的後端語言，搭配 Laravel 提供穩定且成熟的開發基礎。
- **Docker**：用來建立一致的開發與部署環境，降低環境差異造成的問題，並讓服務啟動與維護更直觀。
- **FrankenPHP**：作為執行 PHP 應用的伺服器，整合現代化的 PHP 執行能力，適合搭配容器化環境使用。

## 說明

此專案目前的技術選型以可讀性、部署便利性與後續擴充為主。  
Laravel 提供完整框架能力，PHP 負責核心邏輯，Docker 讓環境更一致，而 FrankenPHP 則可作為執行與提供服務的基礎。

## 後續方向

- 建立更完整的 Wiki 內容管理流程
- 強化部署與執行環境的文件說明
- 逐步補齊專案結構與功能細節
